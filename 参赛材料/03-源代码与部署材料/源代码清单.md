# 源代码与部署材料清单

## 必交文件

- `index.html`、`server.mjs`、`db.mjs`、`channels/im.mjs`
- `styles/`、`assets/`（界面与图标资源）
- `data/finance.sqlite`（模拟演示数据）
- `package.json`（零 npm 运行时依赖，故无 package-lock）
- `README.md`、`ARCHITECTURE.md`、`DEPLOY.md`
- `output/pdf/zhongan-ai-banking-agent-technical-design.pdf`（技术文档 PDF）
- `output/pdf/zhongan-security-self-assessment.pdf`（安全自评报告：权限分级实现说明与已知风险清单）
- `参赛材料/01-技术文档/`、`参赛材料/03-源代码与部署材料/`

## 启动与测试文件

- `scripts/start-with-free-model.mjs`（启动编排）
- `scripts/start-qwen-tts.cmd`、`scripts/qwen-tts-server.py`（语音服务）
- `scripts/seed-db.mjs`（数据种子与重置）
- `scripts/check.mjs`（静态 + 接口契约）
- `scripts/smoke.mjs`（浏览器端到端，329 条）
- `scripts/im-check.mjs`（IM 通道，55 条）
- `scripts/visitor-check.mjs`（访客隔离，25 条）
- `scripts/prune-visitors.mjs`（访客容量维护）
- `scripts/package-submission.mjs`（生成本提交包）
- `packaging/`（Electron EXE 与 Android APK 打包配置）

## 不纳入提交包

- `node_modules/`、`models/` 中的本地模型权重
- `dist/`（EXE/APK 构建产物）、`packaging/*/node-runtime`、Gradle 构建目录与 `local.properties`
- `.git/`、`.mimosa/`、`.zcode/`、`tmp/`
- 运行日志、截图和浏览器缓存
- `data/ai-config.local.json` 等本机 API Key 配置（服务端密钥只经环境变量注入）
- 内部运维文档 `SERVER_OPS.md`（含服务器地址，仅内部保留）
