# 参赛材料目录

按官方材料清单整理为四个必交项：

1. [01-技术文档](./01-技术文档/)：系统架构、核心算法、SQLite 数据模型、权限与 IM 契约。
2. [02-答辩材料](./02-答辩材料/)：24 页答辩材料 PPT，内嵌当前 Web 界面证据与动画。
3. [03-源代码与部署材料](./03-源代码与部署材料/)：源码压缩包、启动方式、部署说明、测试命令和交付边界。
4. [04-安全自评报告](./04-安全自评报告/)：权限分级、审计、注入拦截、异常熔断、IM 边界与验收结果。

提交时优先使用本目录中的文件；源码压缩包已经排除 PPT、构建产物、模型权重、日志和本机密钥。

如果提交页面只允许逐个选择文件，可直接打开 [上传文件](./上传文件/)；其中四个带编号的文件分别对应官方四项，按页面顺序逐个选择即可。
