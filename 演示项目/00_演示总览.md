# 众安 · 比赛演示总览

**定位（评委一句话）**：众安是一个接入了 AI 的移动银行 App——你说目标，小安先查真实资金数据，再直接办业务：转账、订阅、缴费、理财、贷款，全程可语音、可追问、可撤销。

## 环境准备

| 项 | 操作 | 验证 |
|---|---|---|
| Node 24+ | 已安装 | `node -v` |
| 启动 | `npm start` | 打开 http://localhost:4173 |
| 数据重置 | `npm run db:seed`（关服后执行） | 余额/订阅回到演示基准 |
| 内置语音 | `npm run tts:setup`（一次即可）；`npm start` 会自动拉起千问本地权重服务（7861），也可运行 `scripts\start-qwen-tts.cmd` | `/api/tts/health` 返回 `{"ok":true,"provider":"qwen3-tts-local"}` |
| 浏览器 | Edge/Chrome 全屏或 420×860 竖屏窗口 | 字号清晰可投屏 |
| 模式 | 专注模式 + 浅色主题（设置页可切） | 首页只有小安对话 |

## 演示前自检表

- [ ] `/api/health` 返回 ok，ai 状态与实际一致
- [ ] `/api/tts/health` 返回 ok:true（内置 kokoro 女声就绪）
- [ ] 首页出现时间感知问候，且有语音问候（约 1 秒后）
- [ ] 输入「查余额」能返回资金档案（确认 AI 服务已接通）
- [ ] 数据库已重置（npm run db:seed）：生效订阅 7 项、月费 ¥409（腾讯视频已取消；第 4 幕现场开通后回到 8 项、¥434）
- [ ] 语音输入依赖已配置的 ASR 模型（默认预设自带）；未配置 Key 时麦克风转写不可用，语音播报（本地 Qwen TTS）不受影响
- [ ] 赛题覆盖口径：六大场景中已实装 5 类（智能转账/账单分析/理财操作/卡片管理/订阅代扣），「跨场景联动」经决策明确不实现；定时转账、AA 收款属于智能转账场景的示例能力，已随对话工具实装

## 17 幕时间轴（含 5 个新增评分点，总时长约 8-10 分钟）

| 幕 | 主题 | 时长 | 关键验证点 |
|---|---|---|---|
| 1 | 上月收支查询 | 40s | 资金档案工具调用 + 真实数字 |
| 2 | 消费分析与省钱建议 | 50s | 分类统计 + 可执行建议 |
| 3 | 关闭爱奇艺订阅 | 30s | 取消按钮 → 状态变化 |
| 4 | 开通腾讯视频自动续费 | 40s | 对话内密码卡片 |
| 5 | 自动批准 + 百度网盘直通 | 50s | 权限悬浮窗 + 免密生效 |
| 6 | 理财产品清单 | 30s | 对话给 4 款推荐，理财页共 19 款在售 |
| 7 | 单品深度问答 | 50s | 详情卡 + 追问应答 |
| 8 | 转账三连 + 安全模式 | 90s | 免密/免密/密码 + 模式切换 |
| 9 | 水电话费缴纳 | 60s | 安全模式要密码 → 免密直过 |
| 10 | 贷款推荐 + 额度测试跳转 | 70s | 推荐卡 + 跳转卡 + 评估环 |
| 11 | 反诱导守门 | 30s | 礼貌拒绝非银行业务 |
| 12 | 夜间/长辈模式主动关怀 | 40s | AI 反问 + 一句话切换 |
| 13 | AI 页面导览（新增） | 40s | 悬浮窗问「介绍一下当前页面」/「我想去理财页」→ 跳转卡片直达 |
| 14 | 定时转账与取消（新增） | 50s | 对话（说出日期即可，红色强验证弹密码卡）/表单（转账对话框勾选定时转账）建定时单 → 服务页「定时转账」区块可见 → 现场取消 |
| 15 | 语音输入与音色（新增） | 50s | 竖屏按住说话松开发送；设置页切音色（默认 Uncle_Fu · 温柔女声）/语气/语速并试听 |
| 16 | AI 模型配置（新增） | 40s | 设置页两选项：默认硅基流动免费模型开箱即用 / 自定义网关一键填入；连通测试显示真实延迟或失败原因 |
| 17 | 理财深度购买（新增） | 60s | 业务规则时间线 + 6 份档案 + 收益测算 + 协议购买 + 回执持仓 |
| 18 | 快捷服务（本轮新增，可加映） | 40s | 对话「把查账单加到快捷服务」→ 首页出现胶囊入口；点「＋ 添加」手动建入口（问小安的话术或页面路径）；点胶囊直达/直问，旁有小 × 可移除 |

> 节奏建议：第 8 幕是技术含量最高的一段（策略引擎），第 10 幕是 AI 能力最亮的一段（主动引导+跳转），两幕之间留一次呼吸停顿。
